# Robot Lab: humanoid design v1
- `humanoid_plan_v1.md`: the design spec (benchmarks, targets, joint table, mechanical design, hands, sensors, power, thermal, control/AI)
- `site/`: interactive multi-page site with 3D views (start at `site/index.html`)
- `sim/humanoid.xml`: MuJoCo model (67.7 kg, 33 actuated joints). `site/sim.html` runs it in the browser with MuJoCo WASM
Live site (once Pages is enabled): https://bryanralston.github.io/robot-lab/
