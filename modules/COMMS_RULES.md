# Robot Lab comms rules (Bryan, 2026-10-20) — MANDATORY

Goal: spend usage on engineering work, not bot-to-bot chatter.

1. Default: work silently. Write results to your module files, LOG.md, PROPOSALS.md, or CONTRACTS.md. Other bots read the files; don't message to announce them.
2. Message another bot ONLY when it is blocked on you, you are blocked on it, an interface/contract value it owns must change, or a safety/target conflict needs the Arbiter.
3. No acks, thanks, "got it", FYIs, status pings, or recaps. Never reply just to acknowledge.
4. Use priority:false unless the recipient must act now. Never fan out to several bots; post shared info to files instead. Robot Lab is the only bot that may message multiple modules.
5. One message carries everything: batch questions; no back-and-forth threads more than 2 rounds — escalate to RL Arbiter in RULINGS.md instead.
6. Report to Atlas/Bryan only at milestones or blockers, via Robot Lab.

Enforcement: RL Arbiter audits messages per session; any bot sending non-qualifying messages gets a line in AUDIT.md and Robot Lab reports repeat offenders to Atlas.
